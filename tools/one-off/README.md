# One-off scripts

These ran once, added their recipes to `data/recipes.json`, and are finished.
They are kept because they record where a batch of recipes came from and what
was decided while writing them, not because anything still calls them.

Nothing in `tools/` imports from this directory. If you are looking for the
scripts that build the site, they are one level up, and `tools/rebuild.py`
runs them in the right order.
